# Bus Delay Predictor (Hack the Burgh 2026)

## Setup
1. Clone this repository.
2. Open in VS Code.
3. When prompted, click **"Reopen in Container"** (or open Command Palette `Cmd+Shift+P` / `Ctrl+Shift+P` -> `Dev Containers: Reopen in Container`).

## Port Allocation
- `3000`: React / Frontend (if used)
- `8000`: FastAPI / Python Backend (if used)
- `8501`: Streamlit Dashboard (if used)
